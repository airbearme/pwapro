## 2026-02-25 - Unprotected Administrative Endpoints and Middleware Misconfiguration
**Vulnerability:** Critical administrative endpoints (/api/setup/*, /api/spots/update, /api/airbear/update-location) were completely unprotected, allowing unauthorized data modification. Additionally, the security middleware was misconfigured (named proxy.ts instead of middleware.ts), preventing session refresh and application of security headers.
**Learning:** Next.js middleware MUST be named middleware.ts to be correctly executed by the framework. Administrative protection should be centralized in middleware using timing-safe comparisons of a shared secret (ADMIN_SECRET) to prevent side-channel attacks. Reusing authentication results in middleware improves performance.
**Prevention:** Always verify middleware naming and execution. Use robust environment variable resolution that handles multiple possible naming variants (e.g., standard vs. PWA4) to ensure configuration is always loaded.
